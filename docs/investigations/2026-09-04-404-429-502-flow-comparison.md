# 404 vs 429 vs 502 完整流程对比

## 404 流程（一直打上游）

1. **分类阶段** (`upstream_feedback.rs:724`)
   ```rust
   404 → FailureClass::ProtocolUnsupported
   ```

2. **is_temporary()** (`state/types.rs:55-65`)
   ```rust
   ProtocolUnsupported.is_temporary() = false  // ❌ 不是临时失败
   ```

3. **terminal_failure()** (`route_attempts.rs:980-987`)
   ```rust
   所有失败都是 ProtocolUnsupported
   → 返回 TerminalFailure::ProtocolUnsupported
   ```

4. **主循环决策** (`gateway.rs:8870-8875`)
   ```rust
   round_terminal = Some(TerminalFailure::ProtocolUnsupported)
   ```

5. **重试判断** (`gateway.rs:9130-9145`)
   ```rust
   match round_terminal {
       Some(TerminalFailure::Temporary { .. }) => {
           // 调用 decide_with_reason，进入重试预算
       }
       _ => None,  // ← 404 走这里，直接放弃
   }
   ```

6. **结果**
   - **不进入重试循环**
   - **不消耗 max_rounds 预算**
   - **每个请求都是独立的一轮**
   - **404 错误直接返回给下游**

## 429 流程（B3 门关闭时立即放弃）

1. **分类阶段** (`upstream_feedback.rs:697-720`)
   ```rust
   429 → FailureClass::RateLimited 或 KeyQuota
   ```

2. **is_temporary()**
   ```rust
   RateLimited.is_temporary() = true  // ✅ 是临时失败
   ```

3. **terminal_failure()** (`route_attempts.rs:938-954`)
   ```rust
   有任何 temporary 类
   → 返回 TerminalFailure::Temporary { retry_after }
   ```

4. **主循环决策** (`gateway.rs:8870-8875`)
   ```rust
   round_terminal = Some(TerminalFailure::Temporary { retry_after })
   ```

5. **重试判断** (`gateway.rs:9130-9145`)
   ```rust
   match round_terminal {
       Some(TerminalFailure::Temporary { retry_after }) => {
           // 调用 decide_with_reason
           let retry_decision = route_retry_policy.decide_with_reason(...)
       }
   }
   ```

6. **B3 门拦截** (`route_retry.rs:270-289`)
   ```rust
   if client_retryable_rate_limit && !self.rate_limit_internal_retry_enabled {
       return (None, None);  // ← B3 门关闭时，立即放弃
   }
   ```

7. **结果（B3 门关闭）**
   - **进入重试判断，但被 B3 门拦截**
   - **立即返回 (None, None)**
   - **429 直接返回给下游**
   - **不消耗 max_rounds 预算**

8. **结果（B3 门打开）**
   - **进入重试循环**
   - **等待 retry_after（被 cap 限制）**
   - **消耗 max_rounds 预算**
   - **3 轮后报 upstream_routes_exhausted**

## 502 流程（冷却阻断）

1. **分类阶段** (`upstream_feedback.rs:735-760`)
   ```rust
   502 + 空 body → FailureClass::EdgeProxyError
   502 + 其他 → FailureClass::TransientServer
   ```

2. **is_temporary()**
   ```rust
   EdgeProxyError.is_temporary() = true  // ✅ 是临时失败
   TransientServer.is_temporary() = true  // ✅ 是临时失败
   ```

3. **健康观测** (`gateway.rs:520-590`)
   ```rust
   record_route_attempt() 记录失败
   → observe_route_set_failure() 写入冷却
   ```

4. **冷却计算** (`route_health.rs:2320-2345`)
   ```rust
   EdgeProxyError: base=5s, max=60s
   step 0: 5s
   step 1: 10s
   step 2: 20s (max_step=2)
   ```

5. **下一轮请求** (`route_health.rs:1040-1065`)
   ```rust
   // 正常模式
   reserve() 检查路由健康
   → 发现 cooldown_until > now
   → 返回 RouteAvailability::Cooling { retry_after }
   → 候选列表中跳过此路由
   ```

6. **零物理尝试** (`gateway.rs:8870-8920`)
   ```rust
   round_ledger.attempt_count() == 0
   round_ledger.is_all_cooled_transient_family() = true
   → round_terminal = Some(Temporary { retry_after })
   ```

7. **重试判断**
   ```rust
   decide_with_reason() → 等待最早恢复的路由
   → sleep(retry_after)
   → 下一轮继续尝试
   → 消耗 max_rounds 预算
   ```

8. **结果（正常模式）**
   - **路由被冷却 5s→10s**
   - **冷却期间零物理尝试**
   - **等待恢复后再次尝试**
   - **3 轮后报 upstream_routes_exhausted**

9. **结果（透传模式 enforcement_enabled=false）**
   ```rust
   reserve() 直接返回 Ready
   → 每个请求都真实打上游
   → 502 原样返回给下游
   ```

## 关键差异总结

| 特性 | 404 (ProtocolUnsupported) | 429 (RateLimited) B3关 | 429 (RateLimited) B3开 | 502 (EdgeProxyError) 正常 | 502 (EdgeProxyError) 透传 |
|-----|--------------------------|----------------------|---------------------|------------------------|------------------------|
| is_temporary() | ❌ false | ✅ true | ✅ true | ✅ true | ✅ true |
| terminal_failure | ProtocolUnsupported | Temporary | Temporary | Temporary | Temporary |
| decide 调用 | ❌ 不调用 | ✅ 调用 | ✅ 调用 | ✅ 调用 | ✅ 调用 |
| B3 门拦截 | - | ✅ 拦截 | ❌ 通过 | - | - |
| 路由冷却 | ❌ 无 | ✅ 有 | ✅ 有 | ✅ 有 | ⚠️ 记录但不阻断 |
| reserve() | Ready | Cooling | Cooling | Cooling | Ready (透传) |
| 物理尝试 | 每次都打 | 0次 | 几次后 0 | 几次后 0 | 每次都打 |
| max_rounds | 不消耗 | 不消耗 | ✅ 消耗 | ✅ 消耗 | 不消耗 |
| 最终结果 | 404 直接返回 | 429 直接返回 | routes_exhausted | routes_exhausted | 502 直接返回 |

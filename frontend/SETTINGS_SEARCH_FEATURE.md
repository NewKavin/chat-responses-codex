# 设置页面搜索和美化功能

## 实现的功能

### 1. 搜索功能 ✅
- **搜索框位置**：页面顶部，设置状态栏下方
- **搜索范围**：
  - 配置项 key（如 `upstream_route_health_enforcement_enabled`）
  - 配置项标签（如 "路由健康执行"）
  - 配置项描述
- **实时过滤**：输入时立即更新结果
- **搜索高亮**：匹配的文本用 `<mark>` 标签高亮显示
- **分组标签**：搜索模式下每个字段显示所属分组（如 "网络"、"路由"）
- **搜索提示**：显示找到的配置项数量（如 "找到 5 项配置"）
- **无结果提示**：没有匹配项时显示友好提示

### 2. 布局美化 ✅
- **搜索容器**：圆角边框、淡色背景、合理的内边距
- **字段行**：
  - 增大间距（32px gap）
  - 调整列宽比例（280px-1fr + 320px-480px）
  - hover 效果：悬停时显示浅色背景
  - 行高增加（20px padding）
- **标签样式**：
  - 圆角更大（6px）
  - 统一高度（22px）
  - 更清晰的字体（11px）
  - 分组标签使用 info 类型（淡蓝色）
- **字体大小优化**：
  - 标签标题：14px（原 13px）
  - 描述文字：13px（原 12px）
  - key 显示：11px（原 10px）
- **高亮样式**：
  - 黄色柔和背景（`--crc-warning-soft`）
  - 深色文字、粗体
  - 圆角、内边距

## 使用方法

1. 打开 Admin > 设置页面
2. 在顶部搜索框中输入关键词
3. 实时看到过滤结果
4. 匹配的文字会高亮显示
5. 每个字段显示所属分组标签
6. 清空搜索框恢复所有配置项

## 搜索示例

| 搜索词 | 预期结果 |
|--------|---------|
| `enforcement` | 显示所有包含 "enforcement" 的配置项（如路由健康执行） |
| `retry` | 显示所有重试相关的配置项 |
| `timeout` | 显示所有超时相关的配置项 |
| `429` | 显示 B3 门开关（描述中包含 429） |
| `透传` | 显示透传模式相关配置 |

## 技术细节

- **Vue 3 Composition API**：使用 ref 和 computed
- **Element Plus**：使用 el-input 和 el-tag
- **正则表达式**：转义特殊字符避免 XSS
- **响应式设计**：保持现有的响应式布局
- **主题适配**：使用 CSS 变量（`--crc-*`）
- **性能**：computed property 自动缓存
